# کاف و کوکب | Kaf-o-Kokab

**اپلیکیشن جامع طالع‌بینی، خودشناسی و تحلیل شخصی**

A professional Persian-first astrology, numerology, palmistry, face analysis, Tarot, Hafez and self-discovery super-app.

---

## Vision
Build one of the highest-quality Persian lifestyle & self-discovery applications available on CafeBazaar, Google Play and later the App Store.

## Tech Stack
- Kotlin
- Jetpack Compose (Multiplatform-ready)
- Clean Architecture + MVVM + Repository + UseCase
- Room (offline planetary data)
- Firebase Auth + In-App Purchases
- Hilt
- Material 3 + Custom Glassmorphism Design System
- Vazirmatn font + full RTL
