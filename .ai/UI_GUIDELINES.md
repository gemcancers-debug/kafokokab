# UI_GUIDELINES.md

## Design Philosophy
Luxurious • Feminine • Calm • Mystical • Modern Glassmorphism

## Color Palette

| Name              | Hex       | Usage                          |
|-------------------|-----------|--------------------------------|
| Dark Galaxy       | `#0B0014` | Main background                |
| Neon Pink         | `#FF4081` | Primary accent, CTAs           |
| Mystic Purple     | `#9370DB` | Secondary, cards, accents      |
| Gold              | `#FFD700` | Premium, locks, highlights     |
| Soft White        | `#F8F0FF` | Primary text                   |
| Muted Lavender    | `#C9B6E4` | Secondary text                 |

## Typography
- Primary Font: **Vazirmatn** (excellent Persian + Latin support)
- Sizes must be LARGE and highly readable
- Full RTL support is mandatory everywhere

## Core Components

### Glassmorphism Card
- Frosted glass effect (blur + semi-transparent background)
- Soft low-opacity border (white/purple)
- Rounded corners (16–24.dp)

### PremiumBlurBox (Critical)
Reusable composable used for all paid deep features:
- Strong blur over the locked content
- Centered gold lock icon
- Subtle text: «باز کردن با اشتراک ویژه»
- Must feel premium, never annoying

## Spacing & Layout
- Strict 8.dp grid
- Generous padding for luxurious feel
- Avoid dense, crowded screens

## Animation
- Soft and calm (300–500ms)
- Prefer fade + gentle scale
- No aggressive or playful motion

## Accessibility
- High contrast text
- Large touch targets
- Support dynamic font scaling
